# Редизайн «Музейного маршрута», 30 октября 2026

По запросу Юрия все шесть разделов, диалог музея и мобильные состояния переданы в ChatGPT через именованную сессию Browser Bridge `museums-redesign`. Переданы девять снимков публичного сайта и описание действующих функций, без ключей и локальных исходных кэшей.

Диалог: https://chatgpt.com/c/6ae493d3-9070-83eb-a51b-f2fa2bf58028

[Исходный дизайн-борд](design-board-20261030.png). В реализации использована первая концепция: кремовый фон, лесной зелёный, терракота, Playfair Display для заголовков и Inter для интерфейса. Шрифты хранятся локально в WOFF2 вместе с лицензиями SIL OFL.

Перевёрстаны каталог, карта, афиша с неделей/месяцем/годом, билеты и льготы, Telegram, источники и модальная карточка музея. На телефоне доступны раскрывающееся меню всех разделов и панель каналов. На карте добавлен список первых 12 выбранных музеев и действия показа точки/открытия карточки. Дополнительные фильтры раскрываются отдельно; фильтры каталога сохраняют влияние на остальные разделы.

Из макета взят визуальный язык. Демонстрационные цены, отзывы, популярность и неподтверждённые фотографии музеев не переносились. Карточки используют абстрактные тематические иллюстрации. Отдельный коллаж заказан в том же ChatGPT и используется только как декоративное изображение в шапке. Происхождение записано в `web/assets/credits.json`.

Данные, парсеры, ежедневное задание и запрет внешних LLM API для обработки каталога не менялись. При повреждённом названии источника тарифов интерфейс показывает его домен; исходные сведения остаются сохранены.

Проверка: `python serve.py --port 8768`, затем `python scripts/verify_redesign.py`. Драйвер — изолированный headless Chrome через установленный Playwright. Публикация — обычный `scripts/publish.ps1`.
